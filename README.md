# Gestor de inventario con listas en Python

## Descripción del proyecto

Este proyecto consiste en un programa de consola que permite administrar el inventario de una tienda pequeña. Permite registrar productos, consultar sus cantidades, modificarlas, eliminarlas y mostrar un resumen del inventario.

## Requisitos para ejecutar el programa

- Tener Python instalado.
- Tener Visual Studio Code u otro editor de código.
- Descargar el archivo `main.py`.

## Instrucciones de uso

1. Abrir el archivo `main.py`.
2. Ejecutar el programa.
3. Seleccionar una opción del menú escribiendo el número correspondiente.
4. Seguir las instrucciones que aparecen en la consola.
5. Seleccionar la opción 8 para salir.

## Funciones implementadas

- Registrar productos y sus cantidades.
- Mostrar el inventario completo.
- Buscar productos por nombre.
- Modificar cantidades.
- Eliminar productos.
- Contar los productos registrados.
- Mostrar el producto con mayor cantidad disponible.

## Uso de las listas

Se utilizan dos listas paralelas llamadas `productos` y `cantidades`. Los elementos que se encuentran en la misma posición corresponden al mismo producto. De esta manera, se pueden registrar, consultar, modificar y eliminar los productos manteniendo sus cantidades relacionadas.

## Limitaciones

Los datos se guardan únicamente mientras el programa está funcionando. Al cerrar el programa, el inventario se pierde.
